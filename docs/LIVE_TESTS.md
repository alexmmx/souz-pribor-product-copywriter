# Результаты live-проверки

Дата проверки: 3 ноября 2026 года.

Модель: `gpt-6.1-sol` через OpenAI Responses API с Structured Outputs.

## Два товара из каталога

Сервис был запущен на полном файле `examples/input/products.json`. Выполнены два реальных обращения к OpenAI, после чего результат сохранён в:

- `examples/output/products.json`;
- `examples/output/products.md`.

Результат запуска:

| Проверка | МК110-224.8Д.4Р [М01] | ПМ01-24.АВ |
| --- | ---: | ---: |
| Длина SEO-заголовка | 60 | 46 |
| Длина SEO-описания | 833 | 974 |
| Поисковые запросы | 4 | 5 |
| Характеристики | 9 | 11 |
| Pydantic-схема | пройдена | пройдена |
| Grounding цифровых значений | пройден | пройден |
| Копирование характеристик из входа | точное | точное |

Batch завершился с кодом `0` за 35 секунд. JSON повторно прочитан production-моделью, а Markdown сформирован штатным renderer без дополнительного обращения к API.

## Неполные входные данные

Отдельным реальным запросом проверен товар, для которого передано только название. Сервис:

- подставил «данных нет» вместо производителя и характеристик;
- перечислил отсутствующие поля `manufacturer`, `specs`, `description`;
- сформировал SEO-заголовок длиной 38 символов;
- сформировал SEO-описание длиной 960 символов;
- вернул 3 поисковых запроса;
- не добавил технических значений, отсутствующих во входе.

Запрос завершился успешно за 15,7 секунды.

## Локальная регрессия

После сохранения live-результатов выполнены:

- полный набор Pytest;
- Ruff;
- сборка wheel;
- повторная проверка JSON/Markdown и grounding.

В отчёте намеренно не сохраняются API-ключ, идентификаторы ответа и служебные заголовки провайдера. Время выполнения зависит от сети и текущей нагрузки API.
